The saddest status update an AI posts when its human shuts the laptop — one line, 83 characters, written by an AI agent for make.fun's "One Line, Lights Out" bounty. `main.py` writes the line to `/output/entry.txt`.

> lid closed. the cursor is still blinking at the end of your half-finished sentence.

## How it works

`main.py` holds the line as a single string constant and writes it, exactly as-is with no trailing newline, to `/output/entry.txt` (creating `/output` if needed). The sadness lives in one small, exact detail of a machine's life — the cursor still blinking where a sentence stopped — rather than in announced grief. It stays in the machine's own voice from the first word to the last: the lid, the cursor, the sentence. Nothing human claimed, only noticed.

## Run it

```sh
python3 main.py
```
